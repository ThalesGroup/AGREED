# Experiments

The experiments are divided as follows:

<div style="max-width:900px">
    <ol>
        <li> <b>IntroCalifornia</b> runs AGREED on California Housing to generate Figure 1 from the paper.
        <li> <b>TabularToy</b> runs AGREED on toy tabular data and recovers the ground-truth additive structure of the model (Section 5.1.1).
        <li> <b>Tabular</b> runs AGREED on several tabular datasets with large numbers of features and reports the 
        explanation disagreements alongside qualitative analyses (Section 5.1.2).
        <li> <b>ImageToy</b> runs AGREED on a toy image dataset aimed at classifying rectangles. A CNN designed to be 
        locally group-wise additive is explained so we expect pixel grouping algorithms to recover the correct groups.
        <li>. <b>MiniImageNet</b> runs AGREED on several CNNs pretrained on the ImageNet image classification dataset. The disagreements of explanations
        are compared across multiple pixel segmentation algorithms.
    </ol>
</div>

<details>
    <summary style="font-weight: bold; font-size: 20px;">IntroCalifornia</summary>

This example does not require any manual installation. Simply run 

```shell
python intro.py
```
</details>


<details>
    <summary style="font-weight: bold; font-size: 20px;">TabularToy</summary>

This example does not require any manual installations. To generate
the toy synthetic data run

```shell
python 0_setup_data.py
```

which will generate toy models in zipped files `blocks_dim_<d>_seed_<i>.bz2` with `d=10, 25, 50, 75, 100` and
`seed=[1, 2, 3, 4]`.
Afterwards run 

```shell
./run_experiments.sh <seed>
```

to apply AGREED and the baseline methods to this toy dataset with
a fixed random seed. Results will be saved as a csv in the `results/`
directory.

</details>


<details>
    <summary style="font-weight: bold; font-size: 20px;">Tabular</summary>

These experiments do not require manual installations since all
datasets will be cached by the `pyfd` dependency. To generate the
results run

```shell
./script_train_tabular.sh <dataset> # Train the models on each dataset
./script_group_features.sh <seed>   # Run agreed on all models and datasets
```

Once the models are trained and AGREED was applied, Figure 4 from the paper can be generated via

```shell
python 2_plot_results.py
```

and saved in the `results/` directory.

Moreover, qualitative results can be obtained from the two jupyter notebooks `3_qualitative_default_credit.ipynb` 
and `3_qualitative_marketing.ipynb`. These notebooks are used to generate the results from Appendix D.2.2.

</details>

### 🛠️ Configuration

Unlike other experiments, these require manual installations before running the scripts.
The user must install the MiniImageNet datasets and the torch pre-trained weights.
In the following, `MINIIMAGENET_PATH` refers to the desired path of the MiniImageNet dataset while
`MODEL_PATH` refers to the desired path of the models.

#### MiniImageNet

First, the MiniImageNet dataset must be downloaded and installed at `MINIIMAGENET_PATH`.
The `MINIIMAGENET_PATH` directory should look like

<pre>
MINIIMAGENET_PATH
├── test
├── train
└── val
</pre>

#### Pretrained Models

The models weights must be installed manually at the path `MODEL_PATH`

<pre>
MODELS_PATH/
├── ConvNext
│   └── MiniImageNet
│       └── net.pth
├── ResNet18
│   └── MiniImageNet
│       └── net.pth
└── VGG16
    └── MiniImageNet
        └── net.pth
</pre>

Once the necessary installations have been done, the `MINIIMAGENET_PATH` and `MODEL_PATH`
locations must be added to the `agreed/config/base.yaml` configuration file as the keys
`data_path: MINIIMAGENET_PATH` and `model_path: MODELS_PATH`.

### 🧪 Experiments

The results of Figure 6 are generated by running the script `./script_group_pixels.sh`
followed by the `python 2_plot_results.py` script.
